## Commandes Clasp utiles

Ce projet utilise `@google/clasp` pour synchroniser le code local avec Google Apps Script.

### 1. Télécharger les modifications depuis Apps Script (Pull)
```bash
npx @google/clasp pull
# ou
npm run pull
```

### 2. Déployer les modifications locales vers Apps Script (Push)
```bash
npx @google/clasp push
# ou
npm run push
```

### 3. Synchronisation en continu (Watch)
```bash
npx @google/clasp push --watch
# ou
npm run watch
```

### 4. Ouvrir le projet directement dans le navigateur
```bash
npx @google/clasp open
# ou
npm run open
```
